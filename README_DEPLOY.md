# WorkMate v24 — Déconnexion visible

## Nouveautés v24

Ajout d’un bouton de déconnexion visible :

- en bas de la barre latérale
- dans la page Profil, section Session

## Comment se déconnecter

Méthode 1 :
- Clique sur Déconnexion en bas du menu gauche.

Méthode 2 :
- Clique sur ton profil en bas du menu.
- Va dans Session.
- Clique sur Se déconnecter.
