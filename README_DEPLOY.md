# WorkMate v36 — Améliorations UX

## Corrections et améliorations

### Réunion
- Correction du rendu du résultat Réunion.
- Le compte rendu s’affiche bien dans le bloc Réunion, pas dans Documents.
- Ajout du bouton “Nouvelle réunion”.
- Ajout du bouton “Effacer la transcription”.
- Feedback visible après génération du compte rendu.

### Discussions
- Amélioration du nom automatique des discussions.
- Les discussions “Nouvelle discussion” sont renommées plus proprement.
- Ajout d’un bouton “Nettoyer les titres”.
- Les titres sont générés à partir du premier message utile.

### Expérience utilisateur
- Meilleurs retours visuels avec toast.
- Boutons plus clairs dans le module Réunion.
- Interface plus propre sur les modules.

## Déploiement

1. Remplacer les fichiers du repo GitHub par ceux de ce ZIP.
2. Commit changes.
3. Vercel → Deployments → Redeploy.
4. Redéployer sans cache si possible.
5. Recharger le site avec Ctrl + F5.
